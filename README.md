# ac_psu_gate_drive

KiCad 10.0.7 conversion of the Proteus half-bridge gate-driver board
`gate_drive_power_asym_fb_v3_ee10` (2 × Si8271 isolated gate drivers, IXDD609 driving a hand-wound
toroid that supplies the two floating +/− gate rails; 22.4 × 34.9 mm, 2 layers). The board plugs face
to face into the ac_psu baseboard's J1–J4/J6/J8 (`~/dev/ac_psu_kicad`).

- `kicad/gate_drive.kicad_pro` – schematic (2 sheets, generated by `tools/sheets/sheetNN.py`) and PCB
  (`tools/make_pcb.sh`, rebuilt from the Proteus gerbers).
- `fab/` – JLCPCB BOM / CPL / gerbers and the hand-fit list (`fab/README.md`).
- `tools/check_all.sh` – every check (IPC netlist, ERC, footprints, board, DRC, IPC-356 diff,
  gerber round trip); must end with `ALL CHECKS PASSED`.
- `dcm/` – the DCM variant `gate_drive_power_dcm_fb_v3_ee10` (Q1 MMBT3904 primary switch instead of
  DRV3), converted the same way as a self-contained subproject; see `dcm/README.md`.
- `PLAN.md`, `STATUS.md`, `next_prompt.md` – plan, state and findings, next session prompt.

Tools: the proteus2kicad submodule `tools/p2k` (`git submodule update --init`); KiCad AppImage
`~/kicad/kicad-10.0.7-x86_64.AppImage` (never run it with `--version`).
